# Agent Skills portability

Chara's Toolkit's 22 SKILL.md folders use the Agent Skills metadata/content format. Read-only references and per-skill tools can be reused by any compatible agent with the appropriate language/runtime installed. The **global installer**, auto-updater, managed AGENTS.md routing, and six optional TOML roles remain Codex-specific.

For a client other than Codex, prefer the independent skill installer rather than invoking this repository's Codex setup:

    npx skills add https://github.com/cmdr-chara/codex-toolkit --list

After reviewing its selected skill and license notices, install it with the current skills CLI to a supported client using its documented --agent option. For example:

    npx skills add https://github.com/cmdr-chara/codex-toolkit --skill repository-intelligence --agent claude-code
    npx skills add https://github.com/cmdr-chara/codex-toolkit --skill verification-and-release --agent cursor

Verify the installed target directory and runtime support: CLI adapters, hook protocols, permission models, and discovery vary. Do not claim that Mission Control's Codex TOML roles or the Codex-only behavioral capture runner work unchanged in those clients.

Project-local skill recipes generated by scripts/project-verification.mjs also use standard SKILL.md files. A user may copy their reviewed generated folder to their client's supported project-skill directory; do not assume that every runtime automatically scans .agents/skills.

References: https://agentskills.io/specification and https://github.com/vercel-labs/skills
